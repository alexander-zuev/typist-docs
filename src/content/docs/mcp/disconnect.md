---
title: Disconnect Typist
description: Remove Typist MCP access from an MCP client.
---

Remove the `typist` server or connector from your MCP client's settings.

For terminal clients, use the client's MCP removal command. For Claude, ChatGPT, Cursor, and VS
Code, remove Typist from the corresponding connector or MCP settings.

Adding Typist again starts a new browser authorization flow.
