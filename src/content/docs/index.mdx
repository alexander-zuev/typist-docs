## Typist MCP

Typist MCP removes the export, download, and upload loop between your transcript library and an AI
agent.

<CardGrid>
  <Card title="Search transcripts" icon="magnifier">
    Find completed transcripts by title, topic, category, or date.
  </Card>
  <Card title="Read transcript content" icon="open-book">
    Read TXT, SRT, or VTT content in bounded pages that fit an agent context window.
  </Card>
  <Card title="Download exports" icon="download">
    Create one-hour download links for TXT, SRT, and VTT exports.
  </Card>
  <Card title="Read-only by design" icon="padlock">
    Agents cannot create, edit, or delete transcripts.
  </Card>
</CardGrid>
